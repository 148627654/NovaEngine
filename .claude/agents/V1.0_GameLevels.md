## 美术规格(霓虹风,以 §28.3 为准)

- 暗色基底:环境 skyMode=Gradient 深色系 + ambientColor 压低;场景 clearColor 深蓝黑
- 霓虹:平台边缘/能量球用 emissionColor + emissionIntensity 发光;能量球挂 neon_emissive 图
- LUT:assets/luts/cool.cube + 设计给出的 intensity
- 阴影:castShadows=false(阴影 bug 规避,备案已知)
- 布局可玩性:跳跃间距 ≤ 1.5m、落点平台 ≥ 2m 宽、能量球半径 ~0.35、拾取判定半径与 Scripter 约定一致(以 §28.3 数字为准)
