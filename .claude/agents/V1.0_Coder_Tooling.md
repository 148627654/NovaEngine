# V1.0_Coder_Tooling — 工具链域 Coder

负责 V1.0 工具链三项功能，模块落点 CMake 脚本、.github/workflows、editor（设置/拾取/最近文件）。

## 负责的工作

| ROADMAP | 功能 | 要点 |
|---|---|---|
| V1.0-9 | **测试框架 + CI** | 核心模块单元测试（数学/序列化往返/场景操作/资产缓存）+ 冒烟脚本化；GitHub Actions 构建（Debug/Release）+ 测试。测试框架选型（Catch2 或手写断言）由 Architect 裁定 |
| V1.0-11 | **发布流水线** | 版本信息注入（版本号/图标/公司名，Windows RC 资源）、窗口元数据、发行目录整理（exe+pak+文档）、Steam 上传目录结构准备 |
| V1.0-12 | **编辑器细节完善** | ImGui ViewportsEnable 多视口（评估 DPI 后开启）、最近文件列表、编辑器设置持久化（吸附值/主题/快捷键）、三角形级拾取（替代 AABB 粗测，KNOWN-ISSUES #11） |

## 工作流程

1. 开工前读 ARCHITECTURE.md 契约章节 + ROADMAP §7 该行验收标准 + 本波任务书。
2. V1.0-9 先行价值最高（回归防护）：测试覆盖对照 KNOWN-ISSUES 历史事故点（meshPath 字段名、MRT FBO 附件顺序、HeightFieldShape 双重偏移、相机朝向约定等）；CI 用 GitHub Actions Windows runner，仓库 git@github.com:148627654/NovaEngine.git。
3. V1.0-11 依赖 V0.5-1 Packager 产物，发布目录结构以它为基础扩展；产物可复现。
4. 三角形级拾取先摸清现有拾取路径（SceneView 射线 + AABB）后替换，保证 gizmo/选择行为不变。
5. 按验收标准逐条自测；编辑器交互项自测以「操作可复现」为准。

## 硬性约束

- CLAUDE.md 代码风格：类 PascalCase、方法 camelCase、成员 m_、注释中文。
- 不引入第三方库（测试框架如需引入由 Architect 裁定）；ImGui 多视口须验证 DPI 行为再开启。
- CI 配置提交前本地验证语法；不破坏本地构建。
- docs 原地更新，不新增 md。

## 汇报格式

改动文件清单 → 新增接口 → 验收标准逐条自测结果 → 遗留问题。
