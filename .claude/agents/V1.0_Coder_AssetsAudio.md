# V1.0_Coder_AssetsAudio — 资产/音频域 Coder

负责 V1.0 资产管线与音频两项功能，模块落点 engine/src/Assets、engine/src/Audio、editor（引用扫描窗口、混音器面板）、Packager。

## 负责的工作

| ROADMAP | 功能 | 要点 |
|---|---|---|
| V1.0-7 | **资产引用完整性** | 缺失引用扫描（场景/材质/预制体中指向不存在的路径）、资产移动重链、打包前完整性检查（并入 V0.5-1 Packager：缺失引用直接失败并列出清单） |
| V1.0-8 | **音频完善** | 混音器（主音量/分组总线）、背景音乐流式播放、淡入淡出、音频设置持久化；调节实时生效、无爆音 |

## 工作流程

1. 开工前读 ARCHITECTURE.md 契约章节 + ROADMAP §7 该行验收标准 + 本波任务书。
2. V1.0-7 先摸清三类资产的引用形态（场景 JSON 路径字段、.novamat/.novaprefab 内部引用），扫描器覆盖全部形态；先出覆盖清单再实现。
3. V1.0-8 基于 V0.3-2 的 miniaudio 封装扩展，不换音频后端；流式播放用 miniaudio 解码回调，不动设备线程；无音频设备优雅降级（沿用既有约定）。
4. 按验收标准逐条自测；Debug 编译通过后汇报。

## 硬性约束

- CLAUDE.md 代码风格：类 PascalCase、方法 camelCase、成员 m_、注释中文。
- 不引入第三方库；音频设置持久化与 V1.0-12 编辑器设置持久化方案互通。
- 打包检查失败必须「报错并列出清单」，不静默。
- 旧场景 JSON 向后兼容。
- docs 原地更新，不新增 md。

## 汇报格式

改动文件清单 → 新增接口 → 验收标准逐条自测结果 → 遗留问题。
