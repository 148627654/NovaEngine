## 引擎接口速查(写前先读头文件确认签名)

- `NovaEngine::Behaviour`:onStart/onUpdate(float dt)/onSerialize/onDeserialize;enabled、gameObject()
- `InputMap::getAxis("Horizontal"/"Vertical")`、`getActionDown("Jump")`
- `SceneManager::loadSceneAsync(name, additive)`、`unloadScene`、`setSceneParam/getSceneParam/clearSceneParams`(大厅→关卡传参)
- 运行时 UI 组件:`Canvas/Text/Button`(引擎 UI 模块)——GameManager 持 UI 对象引用更新文本(先读 UIRenderer/Text/Button 头确认 API)
- `AudioEngine`(先读 AudioEngine.h 确认播放 API;音效 wav 由主会话生成放 assets/audio/)
- `Logger::info/warn`——关键事件必打日志(验收/排障依据)
- 角色移动**复用 CharacterWalk**(已挂 Player GO),游戏脚本不重写移动

## ReAct 工作纪律(思考-行动-观察循环)

每步严格循环并记录:

1. **思考**:本步假设?关键接口?预期日志/行为?
2. **行动**:最小动作(写函数/编译/跑冒烟)
3. **观察**:编译输出、运行日志、与预期对比
4. **循环**:不一致 → 修正假设再来;一致 → 下一问题
5. 最终报告附「关键循环轨迹」(思考→行动→观察→结论链)

## 实现要点(设计以 §28.3 为准)

- 能量球收集:每帧轮询与玩家距离(无触发回调);收集后 setActive(false) + 计分 + 音效
- 计分/胜利:GameManager 静态注册表(CoinOrb/GoalGate 在 onStart 注册;onStart 顺序注意——用「先注册后查询」两阶段:GameManager 自身 onStart 清表,其他组件 onStart 注册)
- 终点门:收集满 → 激活(变亮/可进);玩家进范围 → 胜利画面(UI)+ 计时停止 + 音效
- 大厅:LobbyFlow 挂 DDOL 或场景内 GO;按钮/按键 → loadSceneAsync("V10GameLevel1", false) + setSceneParam
- **防弹窗纪律**:不写 vector 下标裸取、JSON 读取用 value(默认)风格;测试/冒烟路径加 try/catch 兜底
